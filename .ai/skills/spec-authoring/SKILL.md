# Skill: Specification Authoring

Use for any new behavior or behavior change.

1. Read AGENTS + relevant docs/tests.
2. State problem, actors, preconditions, invariants, success/failure paths.
3. Assign requirement IDs.
4. Define state/contract/error deltas.
5. Mark unknowns explicitly.
6. Write acceptance scenarios before implementation.
7. Update traceability.

Never encode a product decision only in code or a test name.
